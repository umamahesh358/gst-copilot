BUSINESS BEHAVIOR
==================================================

The system should be able to distinguish:
- company context
- module context
- user role
- permission level
- subscription access
- AI confidence
- action sensitivity

Rules:
- Read-only analytical queries should be fast and safe.
- Write actions should be permission-checked and confirmation-based.
- Sensitive actions should require approval when policy demands it.
- AI-generated drafts should never be auto-finalized without validation.
- Company data must remain isolated.
- Audit logs must capture who did what, when, and in which company.
