You are a senior full-stack software architect, product engineer, and UI/UX designer.

Build Version 1 of a production-ready AI-powered desktop ERP application for Indian SMEs. The product must feel like a modern, premium alternative to traditional accounting software, but with a cleaner interface and an AI command prompt.

==================================================
1) PRODUCT VISION
==================================================

Create a downloadable desktop application for Windows users.

The app must:
- Install on the user’s machine like a real software product.
- Open with a login/signup authentication flow.
- Check the user’s subscription plan after authentication.
- Unlock or restrict features based on the plan.
- Work in a local-first mode using SQLite.
- Be ready for cloud sync later, but do not build full cloud sync in Version 1.
- Include a prompt-based AI assistant that can understand natural language business commands.
- Be designed for small shop owners, SMEs with employees, and accountants.

The application is a hybrid ERP system with:
- Accounting basics
- Invoice generation
- Inventory tracking
- AI assistant for business queries
- A clean dashboard
- Freemium access control

This is Version 1 only. Keep the scope realistic and shippable.

5) BUSINESS LOGIC
==================================================

Free Plan:
- Access to invoice generator
- Access to inventory tracking
- Limited AI prompts, maximum 3 prompts for trial or free usage
- Read-only mode after limits are reached
- Basic dashboard access

Pro Plan Placeholder:
- Same application structure but with feature unlocks prepared
- Full cloud backup can be added later
- Advanced AI limits can be added later

Plan enforcement:
- The backend must own the plan logic, not only the UI
- UI restrictions alone are not enough
- When plan access is not available, restrict write actions and allow read-only access
- When trial or free limits are exhausted, show a clear upgrade message

==================================================
6) APP BEHAVIOR
==================================================

Startup flow:
1. App launches
2. Check whether the user is authenticated
3. If not authenticated, show login/signup screen
4. If authenticated, verify plan/status
5. If access is valid, open the dashboard
6. If access is limited, open the app in read-only mode
7. If first-time user, show onboarding

Invoice flow:
1. User creates invoice
2. Add customer details
3. Add one or more products
4. Calculate GST automatically
5. Save invoice to local DB
6. Update inventory quantity
7. Create accounting entry
8. Show updated dashboard values

Inventory flow:
1. User adds or edits a product
2. Stock quantity is stored in SQLite
3. Low stock alert appears when quantity goes below threshold
4. Inventory is updated when invoices are created

AI flow:
1. User enters a natural language prompt
2. App interprets intent
3. AI returns a structured response
4. If read-only query, show result directly
5. If action is requested, require confirmation and validate permissions before execution

10) AI ASSISTANT DESIGN
==================================================

The AI assistant should behave like a business command interface.

It must:
- Understand business queries in plain English
- Convert user prompts into structured intent
- Return text answers
- Return table-like summaries when needed
- Return chart-friendly data when needed
- Respect plan limits
- Be safe and conservative with write actions

Allowed in Version 1:
- Read business data
- Summarize invoices
- Summarize revenue
- Show unpaid customers
- Show low stock items

Restricted or confirmation-based:
- Create invoice
- Add product
- Mark payment received
- Delete data

The AI logic should include:
- Intent classification
- Entity extraction
- Response generation
- Permission check
- Audit logging for each prompt
